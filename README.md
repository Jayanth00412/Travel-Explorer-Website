# 🧭 Karnataka Travel Explorer

A modern and responsive travel exploration website showcasing famous historical destinations across Karnataka. Users can explore destinations through visually appealing cards and quickly find places using the search feature.

## ✨ Features

- **Interactive Card Layout** – Explore historical destinations through attractive cards.
- **Instant Search** – Search and filter destinations by name.
- **High-Quality Images** – Beautiful destination images for a better visual experience.
- **Responsive Design** – Compatible with desktop, tablet, and mobile devices.
- **Smooth Hover Effects** – Attractive hover animations and transitions.
- **User-Friendly Interface** – Clean and simple navigation for easy exploration.

## 🏛️ Places Covered

- Hampi
- Mysore Palace
- Gol Gumbaz
- Badami Caves
- Aihole
- Belur
- Halebidu
- Shravanabelagola
- Bidar Fort
- Chitradurga Fort
- Pattadakal

## 🛠️ Tech Stack

- **HTML5** – Website structure
- **CSS3** – Styling, layout, responsiveness, and animations
- **JavaScript** – Search functionality and interactive features
- **Unsplash** – Destination images

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start exploring historical places across Karnataka!
